# yahoox 标准文档

**crate**：`yahoox` v0.1.0 | **角色**：Yahoo 源事实的离线类型层

> 采集范围权威：`specs/adapter/yahoo.md`；跨源语义权威：`contracts/cross-source-routing.md`。
> 本文件只描述本库的能力标准，不改变任何授权状态。

---

授权范围逐字匹配 `domain_yahoo_production_release`（Owner 签核 scope）、`domain_yahoo_release`（既有离线证据别名）、`offline_parse_and_types`（本库归一化范围）；三者都只覆盖离线类型与解析。 未知范围、其他源范围或含额外前后缀（包括空白）的范围一律拒绝，不自动裁剪。公开完整性校验重新验证 Day 内部日期，直接修改公开字段不能绕过月、日和闰年规则。

## 1. 需求标准

### 目标

把 Yahoo 源侧的**源事实**表达为稳定 Rust 类型：日线观测、义务集与守卫、离线解析、
fail-closed 授权判定与 publication 语义。

### 边界

- **包含**：`YahooBar` 值对象、`Date` / `Period` / `Frequency` / `Unit`、义务集 11 符与
  禁抢主源 9 符常量、禁静默替换对守卫、`blocked` 采集路径拒绝、离线解析器、
  `YahooAuthorization` 判定、`TimePrecision` / `AvailabilityEvidence` / `PitEligibility` 三元组
- **不包含**：联网采集、凭据管理、代理配置、单位换算、派生指标、存储与分发
- **依赖**：`thiserror`、`serde`、`serde_json`（无 HTTP 客户端、无异步运行时、无日期库）
- **零内部耦合**：不依赖任何 `bytechainx/*` crate，无 `path` 依赖

---

## 2. 设计标准

### 架构

```text
yahoox
├── error   — YahooError / YahooErrorKind / YahooResult
├── value   — Date / Period / Frequency / Unit（基础值对象）
│   ├── value/symbols — 义务集、禁抢主源、禁替换对、blocked 路径与守卫
│   └── value/bar     — YahooBar / YahooValue / validate_bar / unit_for_symbol
├── authz   — YahooAuthorization 与 fail-closed 判定
├── pit     — publication 语义三元组
└── parse   — parse_yahoo_bars（离线、无网络参数）
```

依赖方向单向：`error` ← `value` ← {`authz`, `pit`, `parse`}；`error` 不依赖任何同级模块。

### 数据流

```text
合成样本 JSON（字符串）
  → parse_yahoo_bars：顶层与条目字段白名单（未知字段原子失败）
  → guard_primary_source：禁抢主源 / 义务集外拒绝
  → Period::parse_day：严格 YYYY-MM-DD
  → unit_for_symbol：由符号推导报价口径（样本不得自证口径）
  → validate_bar：完整性校验
  → Vec<YahooBar>
```

## 3. 义务集与禁抢主源

**义务集（`ACTIVE_COLLECTION_OBLIGATIONS`，11 符）**：
`GC=F` `HG=F` `CL=F` `RSP` `TLT` `FEZ` `^STOXX` `IWM` `^RUT` `DX-Y.NYB` `USDCNH=X`。

**禁抢主源（`FORBIDDEN_PRIMARY_SYMBOLS`，9 符）**：
`^GSPC` `^VIX` `^IXIC` `^N225` `JPY=X` `USDJPY=X` `^TNX` `BTC-USD` `ETH-USD`。

`guard_primary_source` 的判据：

| 输入 | 结论 | 错误分类 |
| --- | --- | --- |
| 禁抢主源（9 符） | 拒绝 | `RoutedElsewhere` |
| 义务集（11 符） | 放行 | — |
| 其余符号 | 拒绝（fail-closed） | `Invalid` |

两集**不相交**；本库**不实现采集**，上述常量只作声明层与守卫使用。

## 4. 禁静默替换

`NON_INTERCHANGEABLE_PAIRS` 登记 21 条禁替换对（`cross-source-routing.md` §4 中涉及本域的各行，
外加清单 §2.1 的 `^GSPC` ≠ `SPY`）。左右两列语义不同，**禁止互为别名**。

`guard_non_interchangeable(left, right)` 的判据：命中任一行（**含左右互换**）→
`SemanticallyRejected`；未命中 → 放行。

代表性条目：`^GSPC` ≠ `SPY`、`^IXIC` ≠ `QQQ`、`^IXIC` ≠ `^NDX`、`^N225` ≠ `EWJ`、
`RSP` ≠ `^RUT`、`RSP` ≠ `SPY`、`TLT` ≠ `^TNX`、`CL=F` ≠ `BZ=F`、
`^STOXX` ≠ `^STOXX50E`、`USDCNH=X` ≠ `USDCNY=X`、`DX-Y.NYB` ≠ `DTWEXBGS`、
`JPY=X` / `USDJPY=X` ≠ `DEXJPUS`、`^TNX` ≠ `DGS10`。

## 5. blocked 采集路径

`POLICY-collect-free-first-paid-pause.md` §3.4 的 `blocked` 路径具名为
`YahooCollectionPath` 的四个变体：Python `yfinance`、Cookie / Crumb 自研、
代理轮换与挑战规避、抢 FRED 主源。

| 路径 | `guard_collection_path` 结论 | 错误分类 |
| --- | --- | --- |
| 四个 `blocked` 变体 | 拒绝 | `AuthorizationDenied` |
| `YfinanceRsPublicApi`（R3 放行） | 拒绝（本轮不实现采集） | `NotApplicable` |

R3 政策只**放行**「公开 API + 公开 lib（`yfinance-rs`）」这一条路径，
**不等于**本库实现采集：本层零 HTTP 客户端、零端点字面量、零凭据读取。

## 6. 解析与合成夹具

**输入形态**：单一 JSON 对象。

- 顶层键白名单：`_synthetic`、`_note`、`bars`
- 单条观测键白名单：`symbol`、`period`、`open`、`high`、`low`、`close`、`volume`
- `frequency` 与 `unit` **由符号推导**，样本不得自带（否则即「样本自证」）
- 日期必须严格 `YYYY-MM-DD`（月 / 日两位补零）

**原子失败与重复身份**：出现白名单外的字段 → `SemanticallyRejected`（原子失败，不部分成功）；
重复身份（同 `symbol` + 同 `period`）→ **拒绝**（本库**不做**静默去重）。
数值缺失 MUST 具名表达（`SourceOmitted` / `ExplicitNull`），MUST NOT 静默转 0。

**合成夹具声明**：`tests/fixtures/` 下的全部文件均为本特性**自拟的合成样本**，
**不是真实源数据**，**不构成任何证据**；不得被表述为「实测」「核验 PASS」或任何证据等级。
夹具字段名对齐 `specs/adapter/yahoo.md` 声明的符号与日线形态，不编造清单未提到的端点或字段。

## 7. publication 语义

| 项 | 值 |
| --- | --- |
| `TimePrecision` | `Date` |
| `AvailabilityEvidence` | `Inferred` |
| `PitEligibility` | `NotEligible` |

`is_formal_pit_eligible()` 恒为 `false`：fixture 无发布时刻字段，`21:00 UTC` 缺省占位
被明确拒绝当作正式 publication。MUST NOT 补造 `00:00 UTC` 把 `Date` 伪装成 `Instant`；
日后接入官方字段或经签批日历时须同步更新清单与本文件，**禁止静默升格**。

## 8. 非目标与门禁

**非目标**：不做联网采集、不做凭据与代理、不做单位换算、不做派生指标
（净流动性 / 利差 / z-score 等归 analytics）、不做存储与分发、不做 PIT 升格。

**源码面硬断言（可执行）**：`tests/sdd_spec.rs` 的 S-8 在**运行期递归枚举** `src/` 下全部
`.rs`（以 `CARGO_MANIFEST_DIR` 为根，新增文件自动纳入），逐个断言不含 `http://` / `https://`
端点字面量、不含 `env::var` / `from_env` 凭据读取。

**门禁**：

```bash
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-features
cargo package --no-verify
```

**全公开面 E2E**：`tests/e2e_yahoo.rs`（target `e2e_yahoo`）执行核对器口径内的全部 **115 条**
公开条目（`type` 18 / `variant` 53 / `field` 19 / `const` 6 / `fn` 19）；本 crate 纯离线，用例不加
`#[ignore]`，随 `cargo test` 默认参与 CI。独立三层核对见 `scripts/verify-e2e-coverage.mjs yahoox`。

**诚实边界**：`production_decision = NO-GO`；清单 COMPLETE ≠ ship；
`authorization` ≠ Production Ready。
